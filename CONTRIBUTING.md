# Contributing to Awesome OSINT

Thanks for your interest in contributing!

## Inclusion bar

A pull request is merged when the tool meets one of these:

- **Open source:** at least 100 GitHub stars and a commit in the last 12 months.
- **Commercial service:** at least a year in operation and independent coverage, reviews or a known user base.

Self-submitted listings for new or small commercial services are closed, and so are tools whose main use is abuse (spam sign-ups, account takeover, harassment). Submitting your own project is welcome when it meets the bar. Referral deals and paid placement do not change it.

## Guidelines

### Adding a Tool

- **Actually useful**: Only add tools you've used or thoroughly evaluated.
- **Format**: Follow the existing table format with tool name (linked), stars, language, and a concise description.
- **Active**: Tools should have a commit within the last 12 months. If not, note it.
- **No duplicates**: Check the list first.
- **Right section**: Place the tool in the most relevant category.

### What belongs here

- Open-source OSINT tools, frameworks, and reconnaissance libraries
- Hosted OSINT services and search engines (clearly labeled as commercial)
- People-search, breach, domain, geolocation, and SOCMINT resources
- Supporting tools (datasets, dorking helpers, browser extensions)

### What doesn't belong

- General-purpose utilities that aren't investigation-focused
- Tools with fewer than 100 GitHub stars (unless uniquely valuable)
- Personal scripts or one-off projects
- Tools that only exist to promote a single paid service
- Anything intended primarily for stalking, harassment, or illegal access

### Moving tools to the Graveyard

If a tool is unmaintained (no commits in 2+ years) or officially archived, submit a PR to move it to the Deprecated Tools Graveyard section with a recommended alternative.

## How to Submit

1. Fork the repo
2. Create a branch (`git checkout -b add-tool-name`)
3. Make your changes
4. Submit a PR with a brief explanation of why the tool belongs

## Star Counts

Star counts are approximate and updated periodically. Use `k` notation (e.g., `15k`) for readability.
